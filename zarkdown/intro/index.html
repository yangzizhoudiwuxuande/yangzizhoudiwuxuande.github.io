为什么选择 Zarkdown？

为键盘而生的标记语言

键盘友好

所有符号都在主键区，无需按 Shift 组合键。写作时手指不需要大范围移动。

直观易记

/ 像路径层级表示标题，? 像强调语气表示粗体，符号与语义强关联。

无歧义

每个符号有明确唯一的用途，不会出现同一符号在不同上下文中表示不同含义。

纯文本

任何文本编辑器都能打开，人类可读性强，即使不渲染也能理解结构。

功能完整

支持标题、粗体、斜体、下划线、删除线、超链接、图片、代码块、表格、脚注等。

多格式导出

一键导出 HTML、PDF、Word、LaTeX，满足不同发布场景。

与 Markdown 的对比

更少的按键，更流畅的写作

Markdown 需要 Shift 组合键
# 一级标题 ## 二级标题 **粗体** *斜体* ~~删除线~~ [链接](url)
Zarkdown 全部主键区
/ 一级标题 // 二级标题 ?粗体? \斜体\ -删除线- *链接*(url)

快速开始

选择你喜欢的方式安装

使用 pip 安装 推荐

$ pip install zarkdown

使用 Homebrew (macOS)

$ brew tap yangzizhoudiwuxuande/zarkdown $ brew install zarkdown

基本用法

# 转换 .zkdn 文件为 HTML $ zarkdown example.zkdn -o example.html # 实时预览（保存即刷新） $ zarkdown example.zkdn -w # 导出为 PDF（需安装 Pandoc） $ zarkdown example.zkdn -f pdf
